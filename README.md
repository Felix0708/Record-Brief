# Record-Brief

macOS 메뉴바에서 회의 음성을 녹음하거나 기존 오디오 파일을 읽고, 녹취록과 회의록을 Markdown으로 저장하는 개인용 실험 프로젝트입니다.

음성 전사는 로컬의 faster-whisper로 처리합니다. 화자 추정과 회의록 생성에는 사용자가 설치하고 로그인한 `codex` 또는 `agy` CLI를 사용합니다. **이 단계에서 녹취 텍스트는 선택한 AI 제공자에게 전달되므로 완전한 오프라인 앱은 아닙니다.** Codex 사용량 제한 시 AGY로 자동 전환하는 동작이 있습니다.

## 기능

- 대면 회의: 선택한 마이크 녹음
- 온라인 회의: 마이크와 시스템 오디오를 별도로 녹음하고 전사용 파일로 합치기
- 기존 오디오 파일 가져오기
- 타임스탬프가 포함된 한국어 녹취록
- 표준 회의록, 간략 브리핑, 심층 분석 형식 선택
- 메뉴바 녹음 시간, 최근 결과 폴더, 클립보드 복사, 로그인 시 실행 설정

## 실행 환경

- macOS: 온라인 녹음은 macOS 15 이상
- Python 3.12: 현재 검증한 Python 버전
- Xcode Command Line Tools: 온라인 녹음 도구 및 네이티브 검사 빌드에 필요
- 설치·로그인이 완료된 `codex` 또는 `agy` CLI
- 마이크 권한, 온라인 녹음을 위한 화면 및 시스템 오디오 기록 권한

Whisper 모델은 최초 사용 시 내려받습니다. AI 모델 이름과 사용 가능 여부는 각 CLI 및 계정에 따라 다릅니다. 메뉴에 없는 모델은 직접 입력할 수 있습니다.

## 설치와 실행

저장소를 내려받은 폴더에서 실행합니다.

```sh
./install.sh
```

설치 스크립트는 Python 가상환경과 의존성을 준비하고, 현재 설치 위치를 가리키는 `Record-Brief.app` 실행기를 만든 뒤 메뉴바 앱을 실행합니다. 온라인 녹음 보조 프로그램은 처음 사용할 때 로컬에서 컴파일합니다.

이미 설치했다면 다음 명령을 사용합니다.

```sh
./start.sh
```

Finder에서 `Install.command`, `Record-Brief.command` 또는 생성된 `Record-Brief.app`을 실행할 수도 있습니다. AI CLI 설치와 로그인은 별도로 완료해야 합니다.

## 저장 결과

녹음과 분석 결과는 설치 폴더의 `outputs/` 아래에 저장합니다.

```text
outputs/<session-time>/
├── recording.wav         # 녹음 또는 온라인 오디오 혼합본
├── microphone.wav        # 온라인 모드의 마이크 원본
├── system.wav            # 온라인 모드에서 시스템 오디오가 수신된 경우
├── 녹취록.md
├── 녹취록_화자추정.md      # 추정 생성이 성공한 경우
├── 회의록.md
└── meta.json
```

파일 가져오기는 원래 파일명으로 사본을 보존합니다. 무음, 권한 오류 또는 AI 처리 실패 시 일부 결과 파일이 생성되지 않을 수 있습니다. 온라인 오디오를 합치거나 회의록을 작성하는 데 실패해도 저장된 원본 트랙은 유지합니다.

## 화자 표시와 녹음 보호

`녹취록_화자추정.md`는 **텍스트 문맥 기반 추정**입니다. 목소리 특징을 분석하는 화자 분리가 아니며, 발화자와 이름의 정확성을 보장하지 않습니다. 추정본에는 안내문을 붙이고, 회의록은 추정본 대신 원본 녹취 텍스트를 기준으로 생성합니다. 불명확한 화자·담당자는 미확인으로 표시하도록 요청하지만 결과 검토는 필요합니다.

녹음 중이거나 저장·AI 처리가 진행 중일 때 메뉴의 종료를 차단합니다. 대면 녹음은 파일 저장이 성공한 뒤 메모리 버퍼를 비우며, 저장 실패 시 재시도할 수 있습니다. 강제 종료와 전원 차단까지 복구를 보장하지는 않습니다.

온라인 녹음은 권한을 얻지 못하면 시작하지 않으며 마이크 단독 녹음으로 대체하지 않습니다. 화면 영상은 저장하지 않습니다. 스피커 소리가 마이크에 다시 녹음되는 현상을 줄이려면 이어폰을 사용할 수 있습니다.

## 개발 및 검증

```sh
./venv/bin/python3 test_recording.py
```

합성 데이터와 모의 객체로 다음 항목을 확인합니다. 검사 중 실제 마이크 녹음이나 AI 호출은 하지 않습니다.

- 온라인/대면 녹음 경로 및 권한 오류 처리
- 종료 차단과 저장 실패 후 재시도
- 네이티브 PCM 저장, 마이크·시스템 트랙 시간 정렬, 무음 간격 보존
- 샘플레이트 변환, 믹싱, 클리핑 방지
- 화자 추정 내용이 회의록 입력에 포함되지 않는지 확인
- 네이티브 보조 프로그램 컴파일 및 로컬 코드 서명 검증

실제 장치, macOS 권한, 장시간 회의 및 각 AI CLI와의 통합 동작은 별도 확인이 필요합니다.

## 소스 구성

| 파일 | 역할 |
| --- | --- |
| `menu_app.py` | 메뉴바 UI, 녹음 및 회의록 처리 |
| `audio_capture.py` | 네이티브 도구 실행과 오디오 믹싱 |
| `capture_audio.swift` | ScreenCaptureKit 오디오 캡처 |
| `test_recording.py`, `test_capture.swift` | 합성 데이터 검사 |
| `assets/iconTemplate*.png` | 메뉴바 아이콘 |

## 공개 저장소에 포함하지 않는 파일

`.gitignore`는 검토한 소스와 아이콘만 허용합니다. `outputs/`, `work/`, 가상환경, 생성된 앱 번들, 녹음·회의록·세션·캐시·로그·인증정보는 제외합니다. 새 파일은 내용을 확인한 뒤 명시적으로 허용해야 합니다.

참고: [Apple ScreenCaptureKit](https://developer.apple.com/documentation/screencapturekit/capturing-screen-content-in-macos), [faster-whisper](https://github.com/SYSTRAN/faster-whisper).
